# RBT Exam Prep

Interactive study site for the BACB **Registered Behavior Technician (RBT)** exam, aligned to the RBT Test Content Outline (3rd ed.) used for exams from January 1, 2026.

- 4-week study plan with saved checkboxes
- Cheat sheet + 78 flashcards
- 146 practice questions with explanations, drillable by domain (A–F)
- Full 85-question, 90-minute timed mock exam with domain scoring
- Printable PDFs in `/pdfs`: study plan, cheat sheet, full exam + key, 30-Q quiz + key

Static site — no build step. Deploy by dragging this folder onto https://app.netlify.com/drop or via GitHub Pages.

Independent study material; not affiliated with the BACB. Verify requirements at https://www.bacb.com/rbt/.
